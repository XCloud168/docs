# Bybit API授权教程 - PC端

## 电脑版本：

## 第一步：登录Bybit 账户

1、打开 Bybit 官网：https://www.bybit.com；

2、登录账户；

3、点击右上角头像 >【API】；


![步骤1截图](/images/bybit-pc-step1.png)

## 第二步：创建新的 API 密钥

1、在【API管理】页面，点击【创建新密钥】；

2、选择创建方式：由系统生成；


![步骤2截图](/images/bybit-pc-step2.png)

3、填写API信息：

A.勾选API交易；

B.API备注：例如 Masbate；

C.勾选读写权限；

D.绑定 IP（推荐）：将自己的服务器 IP（如：123.123.123.123）输入在受信任的IP栏中，**一旦启用了 IP 白名单，其他设备将无法访问该 API，极大降低风险**；

E.权限设置：【统一交易账户】>【现货】>【交易】


![步骤3截图](/images/bybit-pc-step3.png)


![步骤4截图](/images/bybit-pc-step4.png)

4、【提交】>【输入验证码】


![步骤5截图](/images/bybit-pc-step5.png)

## 第三步：保存 API 访问信息

系统将生成以下两个重要信息：

API 密钥：填写在Masbate自动化交易凭证的API KEY一栏。

API 密钥密码：填写在Masbate自动化交易凭证的API Secret一栏。

### 重要提醒：

Secret Key 只会显示一次，**请务必妥善保存并备份**。

不要将这两个密钥透露给任何第三方（包括截图分享）。


![步骤6截图](/images/bybit-pc-step6.png)

## 第四步：绑定 API 到 Masbate 自动化平台

1、登录 Masbate自动化交易平台；

2、进入【交易所凭证】>【创建API密钥】；

3、填入您的 API Key 和 Secret Key；

4、选择交易所为【Bybit】；

5、点击【创建】。绑定成功后，即可实现智能交易功能！


![步骤7截图](/images/bybit-pc-step7.png)
