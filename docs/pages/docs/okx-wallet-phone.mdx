# OKX钱包手机端

## 一、创建钱包账户

OKX 钱包是去中心化钱包，创建钱包就等于你拥有一把属于自己的加密货币保险箱。

1、打开 OKX App，点击首页顶部 "web3钱包" 选项。

2、选择 创建钱包（如果你已有钱包，也可以选择“导入钱包”）。系统会为你自动生成一个钱包。


![步骤1截图](/images/okx-wallet-phone-step1.png)

## 备份助记词

助记词 = 你的钱包总钥匙，丢了/泄露了就等于别人能直接搬空你的资产。

1、选择手动备份；


![步骤2截图](/images/okx-wallet-phone-step2.png)

知晓风险；


![步骤3截图](/images/okx-wallet-phone-step3.png)

App 会显示一组 12 个英文单词（助记词），拿纸和笔抄下来（或者其他方式），按顺序写好保管。不要截图、不要放云盘、不要发给任何人。点击备份，会让你 按顺序点击助记词 验证。


![步骤4截图](/images/okx-wallet-phone-step4.png)

## 添加新账户

一个钱包可以有多个账户（多个账户共有一套助剂词），比如一个用来投资，一个用来空投交互。

1、在钱包首页，点击 账户旁边的倒三角按钮。

2、选择 添加账户 → 单个添加（或者批量添加）。


![步骤5截图](/images/okx-wallet-phone-step5.png)

3、创建完成后即可在钱包里切换不同账户。


![步骤6截图](/images/okx-wallet-phone-step6.png)

## 添加新钱包

添加新的钱包,拥有不同的助记词/私钥。

在钱包首页，点击 账户旁边的倒三角按钮，选择 添加钱包；


![步骤7截图](/images/okx-wallet-phone-step7.png)

以导入钱包为例（输入已有助记词、私钥），成功后，你就能在 OKX 钱包里管理多个钱包。


![步骤8截图](/images/okx-wallet-phone-step8.png)

## 转账收款

转账：

选择你要转出的币种（比如 SOL）,点击“发送”按钮


![步骤9截图](/images/okx-wallet-phone-step9.png)

输入收款方的钱包地址（可以粘贴或扫码），输入转账数量。

D.输入支付密码，等待链上确认后转账完成。

收款；

选择你要转出的币种（比如 SOL）,点击“接收”按钮，系统会显示你的收款二维码和钱包地址。

点击复制地址，或让对方扫码转账，等网络确认完成后，资产会出现在你的钱包里。
