# Bybit API授权教程 - 手机端

手机版本：

## 第一步：登录Bybit账户

打开Bybit APP；

点击左上角头像 >【更多服务】>【API管理】

![步骤1截图](/images/bybit-phone-step1.png)

## 第二步：创建新的 API 密钥

在【API管理】页面，点击【创建 API】

输入一个自定义名称，例如 Masbate，点击【创建】

进行二次验证（邮箱、谷歌验证等）

![步骤2截图](/images/bybit-phone-step2.png)

## 第三步：保存 API 访问信息

系统将生成以下两个重要信息：

- **API Key**：填写在Masbate自动化交易凭证的API KEY一栏。
- **Secret Key**：填写在Masbate自动化交易凭证的API Secret一栏。

### 重要提醒：

- Secret Key 只会显示一次，请务必妥善保存并备份。
- 不要将这两个密钥透露给任何第三方（包括截图分享）。

## 第四步：设置 API 权限

找到你刚创建的 API 密钥，点击【编辑】并勾选以下权限：

✅ **启用现货交易**（Enable Spot Trading）

✅ **（如需要）读取权限**（Enable Reading）

❌ **不勾选提币权限、划转等其他权限**（其他权限请务必保持未勾选状态！）

✅ 将自己的服务器 IP（如：123.123.123.123）输入在受信任的IP栏中，一旦启用了 IP 白名单，其他设备将无法访问该 API，极大降低风险；

![步骤3截图](/images/bybit-phone-step3.png)

## 第五步：绑定 API 到 Masbate 自动化平台

1. 登录 Masbate自动化交易平台；
2. 进入【交易所凭证】>【创建API密钥】；
3. 填入您的 API Key 和 Secret Key；
4. 选择交易所为【Bybit】；
5. 点击【创建】。绑定成功后，即可实现智能交易功能！

![步骤4截图](/images/bybit-phone-step4.png)

## 注意事项

- Bybit API 支持现货交易和合约交易，请根据您的需求选择相应的权限。
- 建议启用IP白名单以提高安全性。
- 定期检查API密钥的使用情况。
- Bybit API 有频率限制，请注意控制请求频率。
- 手机端操作相对简单，但建议在PC端进行更详细的权限设置。
