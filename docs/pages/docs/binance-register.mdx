# 币安注册流程

在注册前准备好邮箱/手机号、身份证件，并下载好 Binance App（或用网页）。

### 一、访问币安官网

1、官网：https://www.binance.com

2、点击 “注册”；

3、选择： 邮箱注册 或 手机号注册；

![步骤1截图](/images/binance-register-step1.png)

4、输入邮箱或手机验证码；

![步骤2截图](/images/binance-register-step2.png)

5、创建登录密码（建议包含大小写+数字+符号）；

![步骤3截图](/images/binance-register-step3.png)

6、输入推荐人邀请码: `GRO_20338_1WUYM`

![步骤4截图](/images/binance-register-step4.png)

## 二、实名认证（KYC）

1、选择国家/地区

2、上传身份证 / 护照 / 驾照

3、按提示进行人脸识别（建议光线充足）

4、等待审核（几分钟到几小时）

![步骤5截图](/images/binance-register-step5.png)

![步骤6截图](/images/binance-register-step6.png)

![步骤7截图](/images/binance-register-step7.png)

三、开启安全验证

多重验证能提高资金安全性。需要在 账户安全 中开启：

![步骤8截图](/images/binance-register-step8.png)

1、手机验证；

2、邮箱验证；

3、身份验证器（Google Authenticator）；

A.下载身份验证器，下载成功后点击“启用身份验证器 app”；

![步骤9截图](/images/binance-register-step9.png)

复制币安生成的 16 位密钥;

![步骤10截图](/images/binance-register-step10.png)

![步骤11截图](/images/binance-register-step11.png)

D.完成后身份验证器会生成最新的动态数字验证码，并将最新的验证码输入到币安，即可完成绑定。

![步骤12截图](/images/binance-register-step12.png)
