# OKX API授权教程 - PC端

## 第一步：登录 OKX 官网

1、打开 OKX 官网：https://www.OKX.com

2、登录您的账户

3、点击右上角头像 >【API】


![步骤1截图](/images/okx-pc-step1.png)

## 第二步：创建 API 密钥

点击【创建 API】按钮；


![步骤2截图](/images/okx-pc-step2.png)

2、设置 API 权限：

A、API 名称（如：Masbate）；

B、用途选择【API交易】

C、将自己的服务器 IP（如：1.1.1.1）输入在受信任的IP栏中，一旦启用了 IP 白名单，**其他设备将无法访问该 API，极大降低风险**；

D、勾选读写权限>【现货】>【交易】

E、Passphrase」（API 密码，如：Masbate168$）


![步骤3截图](/images/okx-pc-step3.png)

## 第三步：安全验证

创建 API 时，系统会提示您进行多重身份验证：

1、邮箱、谷歌验证、密码等验证。


![步骤4截图](/images/okx-pc-step4.png)


![步骤5截图](/images/okx-pc-step5.png)

## 第四步：保存 API 信息

成功创建后，点击【显示信息】：


![步骤6截图](/images/okx-pc-step6.png)

## 2、保存信息

## API KEY：填写在Masbate自动化交易凭证的API KEY一栏。

## 密钥：填写在Masbate自动化交易凭证的API Secret一栏。


![步骤7截图](/images/okx-pc-step7.png)

## 第五步：绑定 API 到 Masbate 自动化平台

1、登录 Masbate自动化交易平台；

2、进入【交易所凭证】>【创建API密钥】；

3、填入您的 API Key 和 Secret Key和Passphrase；

4、选择交易所为【OKEX】；

5、点击【创建】。绑定成功后，即可实现智能交易功能！


![步骤8截图](/images/okx-pc-step8.png)
