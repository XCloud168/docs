## 使用说明

1. 点击对应交易所的官网注册链接
2. 在注册页面输入对应的邀请码
3. 按照详细注册教程完成账户注册和实名认证
4. 完成注册后，可参考 [创建交易所 API 凭证](/docs/binance-pc-api) 教程配置 API 密钥

## 注意事项

- 请确保使用官方链接进行注册，避免使用第三方链接
- 注册时务必输入正确的邀请码，以获得相应的注册优惠
- 完成注册后建议立即进行实名认证（KYC），以解锁更多功能
- 建议开启多重安全验证（邮箱、手机、谷歌验证器）以保障账户安全
