# 币安API授权教程 - PC端

建议准备好：邮箱/手机号、身份证件、Google Authenticator（谷歌验证器）APP。

### 一、 访问 Gate.io 官网

1、官网：https://www.gate.io；

2、点击“注册”按钮；

3、选择： 邮箱注册 或 手机号注册；

4、选择输入推荐人邀请码，如：VQVAU19b


![步骤1截图](/images/gate-register-step1.png)

5、输入邮箱或手机验证码；


![步骤2截图](/images/gate-register-step2.png)

6、创建登录密码（建议包含大小写+数字+符号）；


![步骤3截图](/images/gate-register-step3.png)

## 实名认证（KYC）

1、选择国家/地区

2、上传身份证 / 护照 / 驾照

3、按提示进行人脸识别（建议光线充足）

4、等待审核（几分钟到几小时）


![步骤4截图](/images/gate-register-step4.png)


![步骤5截图](/images/gate-register-step5.png)

开启安全验证

建议开启谷歌验证器 + 邮箱+手机三重验证，资金更安全，进入 “安全中心” 开启：

1.邮箱验证；

2.手机验证；


![步骤6截图](/images/gate-register-step6.png)

3、谷歌验证器（Google Authenticator）；

下载身份验证器；

复制GATE生成的密钥;

C.打开身份验证器，点击右上角“+”，将复制的密钥输入到身份验证器，并输入账户名称\服务等资料；


![步骤7截图](/images/gate-register-step7.png)


![步骤8截图](/images/gate-register-step8.png)

D.完成后身份验证器会生成最新的动态数字验证码，并将最新的验证码输入到GATE，即可完成绑定。
