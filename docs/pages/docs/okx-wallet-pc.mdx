## OKX 钱包安装教程

### 一、下载并安装 OKX 插件

打开谷歌浏览器，找到“扩展程序”→“管理扩展程序”→“Chrome 应用商店”

![步骤1截图](/images/okx-wallet-pc-step1.png)

安装：搜索“欧易钱包””→“添加至 Chrome“

![步骤2截图](/images/okx-wallet-pc-step2.png)

![步骤3截图](/images/okx-wallet-pc-step3.png)

### 二、创建账户

创建新钱包，通过助记词，设置每次登录钱包的密码。

备份好助记词。

![步骤4截图](/images/okx-wallet-pc-step4.png)

![步骤5截图](/images/okx-wallet-pc-step5.png)

![步骤6截图](/images/okx-wallet-pc-step6.png)

### 三、钱包充值

选择需要充值的代币，以及选择充值的网络。

![步骤7截图](/images/okx-wallet-pc-step7.png)

充值完成，等待到账即可。
