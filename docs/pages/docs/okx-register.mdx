# 币安API授权教程 - PC端

注册前建议准备好：邮箱或手机号、身份证件、Google Authenticator（谷歌验证器）APP。

### 一、访问 OKX 官网注册

1、官网：https://www.okx.com，点击注册按钮；

2、选择 邮箱注册 或 手机号注册；

3、输入推荐人的邀请码：3377241；


![步骤1截图](/images/okx-register-step1.png)

4、系统会发送验证码到你的邮箱/手机，输入验证码完成验证；


![步骤2截图](/images/okx-register-step2.png)

### 二、实名认证（KYC）

1、登录后进入 “我的 → 身份认证”

2、选择所在国家/地区；

3、选择个人认证；；

4、上传证件照（身份证/护照/驾照）；

5、根据提示进行人脸识别；

6、等待审核（通常几分钟到几小时）；


![步骤3截图](/images/okx-register-step3.png)


![步骤4截图](/images/okx-register-step4.png)

### 三、设置安全验证

建议开启谷歌验证器 + 邮箱+手机三重验证，资金更安全，进入 “安全中心” 开启：

1.邮箱验证；

2.手机验证；


![步骤5截图](/images/okx-register-step5.png)

谷歌验证器（Google Authenticator）；

下载身份验证器，下载成功后点击“绑定身份验证器app”；


![步骤6截图](/images/okx-register-step6.png)


![步骤7截图](/images/okx-register-step7.png)

复制OKX生成的密钥;


![步骤8截图](/images/okx-register-step8.png)

打开身份验证器，点击右上角“+”，将复制的密钥输入到身份验证器，并输入账户名称\服务等资料；


![步骤9截图](/images/okx-register-step9.png)

D.完成后身份验证器会生成最新的动态数字验证码，并将最新的验证码输入到OKX，即可完成绑定。


![步骤10截图](/images/okx-register-step10.png)
