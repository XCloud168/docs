# Phantom钱包插件 - PC端

Phantom钱包插件教程

### 一、下载并安装Phantom钱包插件

打开谷歌浏览器，找到“扩展程序”→“管理扩展程序”→“Chrome 应用商店”


![步骤1截图](/images/phantom-wallet-pc-step1.png)

安装：搜索“Phantom”→“添加至Chrome“


![步骤2截图](/images/phantom-wallet-pc-step2.png)


![步骤3截图](/images/phantom-wallet-pc-step3.png)

### 二、创建账户

创建新钱包，通过“种子短语钱包“，设置每次登录钱包的密码。


![步骤4截图](/images/phantom-wallet-pc-step4.png)

备份好助记词。

### 三、钱包充值

选择需要充值的代币，以及选择充值的网络。


![步骤5截图](/images/phantom-wallet-pc-step5.png)

充值完成，等待到账即可。
