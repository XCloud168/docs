# Metamask钱包插件 - PC端

Metamask钱包插件教程

### 一、下载并安装Metamask钱包插件

打开谷歌浏览器，找到“扩展程序”→“管理扩展程序”→“Chrome 应用商店”


![步骤1截图](/images/metamask-wallet-pc-step1.png)

安装：搜索“Metamask”→“添加至Chrome“


![步骤2截图](/images/metamask-wallet-pc-step2.png)


![步骤3截图](/images/metamask-wallet-pc-step3.png)

### 二、创建账户

创建新钱包，设置每次登录钱包的密码。


![步骤4截图](/images/metamask-wallet-pc-step4.png)

备份好助记词。


![步骤5截图](/images/metamask-wallet-pc-step5.png)


![步骤6截图](/images/metamask-wallet-pc-step6.png)

### 三、钱包充值

添加网络：点击左上角网络按钮，添加需要得网络到钱包。


![步骤7截图](/images/metamask-wallet-pc-step7.png)

添加代币：点击”三个点”按钮→“添加代币“按钮。

输入需要添加的代币名称，并确认添加。


![步骤8截图](/images/metamask-wallet-pc-step8.png)


![步骤9截图](/images/metamask-wallet-pc-step9.png)

选择需要充值的代币，充值完成，等待到账即可。
