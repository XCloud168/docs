# 谷歌验证器教程

谷歌验证器（Google Authenticator）是一种 双重验证工具（2FA），能为你的交易所账户提供额外安全保护。

## 一、准备工作

1、下载谷歌验证器App

A. 在谷歌play中找到：Google 身份验证器

B.点击“安装”按钮，等待应用下载并自动安装

注：如果没有 Google Play 商店，可以使用第三方应用市场下载 APK 文件，但请确保来源可靠。

## 二、绑定交易所账户

打开交易所App（以OKX为例），【用户中心】>【安全设置】>【身份验证App】;


![步骤1截图](/images/google-auth-step1.png)

点击【绑定身份验证App】，接收手机及邮箱验证码，确定已经下载身份验证器；


![步骤2截图](/images/google-auth-step2.png)

交易所会显示一个 二维码 和 16位密钥；

打开谷歌验证器，点击右下角 添加按钮 → 选择 扫描二维码 或 输入设置密钥；

输入账户名称（如OKX）和交易所提供的密钥。


![步骤3截图](/images/google-auth-step3.png)

完成后，App会生成一个 6位动态验证码，每30秒刷新一次。

在交易所输入谷歌验证器显示的6位动态验证码。

点击【确认】完成绑定设置,每次交易所验证谷歌验证器的验证码时，打开谷歌验证器，输入动态验证码即可。


![步骤4截图](/images/google-auth-step4.png)
