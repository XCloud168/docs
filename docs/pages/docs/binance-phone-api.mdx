# 币安API授权教程 - 手机端

## 手机版本：

## 第一步：登录币安账户

打开币安APP;

点击左上角头像 >【更多服务】>【API管理】

![步骤1截图](/images/bnb-phone-step1.png)

## 第二步：创建新的 API 密钥

在【API管理】页面，点击【创建 API】>【系统生成】

输入一个自定义名称，例如 Masbate，点击【下一步】

进行二次验证（邮箱、谷歌验证等）

![步骤2截图](/images/bnb-phone-step2.png)

## 第三步：保存 API 访问信息

系统将生成以下两个重要信息：

API 密钥：填写在Masbate自动化交易凭证的API KEY一栏。

密钥：填写在Masbate自动化交易凭证的API Secret一栏。

### 重要提醒：

Secret Key 只会显示一次，请务必*妥善保存并备份*。

不要将这两个密钥透露给任何第三方（包括截图分享）。

第四步：设置 API 权限

找到你刚创建的 API 密钥，点击【编辑】并勾选以下权限：

✅ 启用现货交易（Enable Spot & Margin Trading）

✅（如需要）读取权限（Enable Reading）

❌ 不勾选提币权限、划转等其他权限（*其他权限请务必保持未勾选状态！*）

✅将自己的服务器 IP（如：123.123.123.123）输入在受信任的IP栏中，一旦启用了 IP 白名单，*其他设备将无法访问该 API，极大降低风险；*

![步骤3截图](/images/bnb-phone-step3.png)

### 若无法勾选“现货及杠杆交易”权限，怎么办？

点击页面上的【开启默认安全控制措施】，返回 API 编辑页面，即可正常勾选【启用现货交易】；

※这是币安近期更新的安全策略，防止用户误操作授权。

![步骤4截图](/images/bnb-phone-step4.png)

第五步：绑定 API 到 Masbate 自动化平台

登录 Masbate自动化交易平台；

进入【交易所凭证】>【创建API密钥】；

填入您的 API Key 和 Secret Key；

选择交易所为【币安 Binance】；

点击【创建】。绑定成功后，即可实现智能交易功能！

![步骤5截图](/images/bnb-phone-step5.png)
