# Gate API授权教程 - PC端

## 电脑版本：

## 第一步：登录 Gate.io 官网

打开 Gate 官网：https://www.gate.io

登录您的Gate账户

点击右上角头像，【账户】>【API Key管理】>【创建API Key】


![步骤1截图](/images/gate-pc-step1.png)

## 第二步：创建 API

1、填写 API 名称，例如：Masbate

2、将自己的服务器 IP（如：123.123.123.123）输入在受信任的IP栏中，一旦启用了 IP 白名单，**其他设备将无法访问该 API，极大降低风险；**

3、配置API 权限，如下：

*※ 勾选【交易账户】；*

*※ 选择 【现货】>【读写】；*

*※ 【Account】>【只读】；*

❌ 不勾选提币权限、划转等其他权限（**其他权限请务必保持未勾选状态！**）

*※ 确认后【提交】*


![步骤2截图](/images/gate-pc-step2.png)


![步骤3截图](/images/gate-pc-step3.png)

## 第三步：安全验证

创建 API 时，系统会提示您进行多重身份验证：

1、风险知晓；

2、邮箱、谷歌验证、密码等验证。


![步骤4截图](/images/gate-pc-step4.png)


![步骤5截图](/images/gate-pc-step5.png)

## 第四步：保存 API 信息

成功创建后，系统将展示：

KEY：填写在Masbate自动化交易凭证的API KEY一栏。

Secret：填写在Masbate自动化交易凭证的API Secret一栏。


![步骤6截图](/images/gate-pc-step6.png)

## 第五步：绑定 API 到 Masbate 自动化平台

登录 Masbate自动化交易平台；

进入【交易所凭证】>【创建API密钥】；

填入您的 API Key 和 Secret Key；

选择交易所为【GATE Binance】；

点击【创建】。绑定成功后，即可实现智能交易功能！


![步骤7截图](/images/gate-pc-step7.png)
